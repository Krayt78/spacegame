## What Is Nexus Protocol?

A **fully on-chain space strategy game** inspired by OGame, deployed on **Polkadot AssetHub**. Every action — building, researching, attacking, colonizing — happens on-chain through smart contracts. No centralized servers. No hidden algorithms. Pure strategy.

Players build interstellar empires: mine resources, construct fleets, research technologies, and wage war against other players in a persistent shared galaxy.

## Tech Stack

- **Smart Contracts:** 10 Solidity contracts on Polkadot AssetHub (EVM-compatible)
- **Frontend:** Next.js 16, React 19, Three.js galaxy map, wagmi wallet integration
- **Testing:** 259+ tests covering all game mechanics
- **Architecture:** Multi-contract pattern (router + domain managers + shared state)

---

## Key Messaging Angles

1. **Fully on-chain** — All game logic lives in smart contracts. No server, no downtime, no trust required.
2. **Zero monetization / No token** — No pay-to-win. No speculative token. Just strategy and time.
3. **Free to try right now** — Testnet deployment means anyone can play at zero cost.
4. **OGame reborn on blockchain** — Nostalgic appeal for strategy gamers who played OGame/Travian, now with true ownership and transparency.
5. **Built on Polkadot** — Leveraging Polkadot AssetHub's EVM compatibility and low fees.
6. **Open source** — Fully auditable code on GitHub.
